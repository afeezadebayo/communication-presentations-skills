## Install

```bash
git clone https://github.com/afeezadebayo/communication-presentations-skills.git
# Claude Code
cp -r communication-presentations-skills/presentation-storyline ~/.claude/skills/
# Codex and other agents
cp -r communication-presentations-skills/presentation-storyline ~/.agents/skills/
```

In Claude.ai or Claude Desktop, zip a single skill folder and upload it under **Settings → Capabilities → Skills**.

Then ask your agent, for example: *"Build the storyline for my board update"* or *"Redesign these slides so each makes one point."*

## Start here

1. Run `presentation-storyline` before opening any slide software.
2. Design with `slide-design`.
3. Rehearse with `presenting-delivery`.
